# 📊 Análise de Recursos Humanos (RH) com Python

Este projeto apresenta uma análise detalhada de Recursos Humanos (RH) a partir de uma base de dados fictícia de funcionários. O objetivo é demonstrar na prática como transformar dados brutos em insights estratégicos que apoiam a gestão de pessoas, retenção de talentos e tomadas de decisão organizacionais baseadas em dados (People Analytics).

## 🗺️ Visão Geral do Projeto

A análise foi desenvolvida utilizando a linguagem Python para explorar indicadores-chave de desempenho (KPIs) de RH, identificar padrões de rotatividade (*turnover*), avaliar a satisfação dos colaboradores e cruzar dados demográficos com métricas de performance.

### 🚀 Principais Análises Realizadas
* **Análise de Turnover:** Identificação dos principais fatores que influenciam a saída de colaboradores.
* **Métricas de Desempenho e Clima:** Cruzamento entre avaliações de performance, tempo de casa e nível de satisfação.
* **Distribuição Demográfica e Salarial:** Estudo da equidade salarial, distribuição por departamentos e faixas etárias.

---

## 🛠️ Tecnologias e Bibliotecas Utilizadas

* **Python** (Linguagem Principal)
* **Pandas & NumPy:** Manipulação, limpeza e tratamento dos dados brutos.
* **Matplotlib & Seaborn:** Construção de gráficos estatísticos e visualizações de dados atraentes.
* **Jupyter Notebook:** Ambiente de desenvolvimento para documentação passo a passo do processo analítico.

---

## 📂 Estrutura do Repositório

* **`/data`**: Contém a base de dados fictícia utilizada na análise (formato `.csv` ou `.xlsx`).
* **`/notebooks`**: Jupyter Notebooks com o código completo, contendo desde o processo de ETL (Extração, Tratamento e Carga) até a análise exploratória visual.
* **`/images`**: Gráficos e insights gerados que podem ser exportados para relatórios executivos ou apresentações.
