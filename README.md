# 📊 Análise de RH

Este projeto apresenta uma análise completa de dados de Recursos Humanos, utilizando Excel para explorar métricas como:
- Total de funcionários
- Salário médio
- Satisfação no trabalho
- Turnover
- Distribuição por gênero e departamento
- Relação entre horas extras e saída da empresa

## 🗂️ Estrutura
- `data/Controle de funcionarios.xlsx` → Base de dados utilizada
- `images/` → Dashboards e gráficos gerados
- `Analise de RH` → Dashboard principal

## 🎯 Objetivo
Demonstrar como dados de RH podem ser transformados em insights estratégicos para apoiar decisões de gestão de pessoas.

## 🔎 Principais Insights

A partir da análise dos dados, alguns pontos se destacam:

1. **Horas extras e turnover**  
   Funcionários que realizam horas extras apresentam maior probabilidade de deixar a empresa. Isso sugere que sobrecarga de trabalho está diretamente ligada ao desligamento.

2. **Satisfação no trabalho**  
   Departamentos com salários mais baixos tendem a ter níveis menores de satisfação. Já áreas como TI e Financeiro, com salários mais altos, apresentam maior retenção.

3. **Distribuição por gênero**  
   A proporção de homens e mulheres é relativamente equilibrada, mas há diferenças na distribuição por departamento: Marketing e RH têm maior presença feminina, enquanto TI e Suporte concentram mais homens.

4. **Escolaridade e permanência**  
   Funcionários com **pós-graduação** tendem a permanecer mais tempo na empresa, enquanto aqueles com apenas **ensino médio** apresentam maior rotatividade.

5. **Idade e turnover**  
   Faixas etárias mais jovens (21–30 anos) concentram maior saída da empresa, indicando desafios na retenção de talentos em início de carreira.
